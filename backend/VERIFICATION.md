# Verification — release 0.4.0 (17 October 2026)

- **87 tests passed**, including all 68 existing C1–C3 tests and 19 C4 policy/API/migration checks. One upstream Starlette/httpx deprecation warning remains; no test failures.
- **Actual TCP/HTTP verification passed** on a temporary migrated SQLite database and uvicorn server: all four pages/docs, C1 calibration/scenarios, C2 original public WAV uploads, C3 four longitudinal synthetic scenarios, and C4 preferences → three comparison offers → activity start → completion → feedback → changed next explanation. The server and temporary database are cleaned up by the verifier. Actual output is in `examples/all_components_http_results.json`.
- New migration `0004` adds five intervention tables. Tests preserve existing C1 facial, C2 voice and C3 daily/prediction records on upgrade. The migrated column sets match the ORM models.
- C4 policy checks independently audit hard constraints over 100 varied preference/time cases and all three strategies. Other checks cover cold-start defaults, exact feedback prior, temporal exclusion/90-day expiry/last-20 cap, generic independence, preference effects, immutable offer/readback and retries, offer expiry, updated exclusions, state-transition guards, completed-only one-time feedback, missing ratings, source separation, consent, API key, owned references, export/deletion and scoped deletion without orphans.
- C4 supplied simulation: 120 artificial people × 28 contexts, seed 418. All three policies have 2,718 eligible starts, 642 empty contexts and zero constraint violations. Mean observed simulated helpfulness: generic 3.275720, preference 3.425727, adaptive 3.406911. Fixed weights were not tuned. These are generated software/simulator results, not human effectiveness. Preference is slightly above adaptive in this run; the full comparison is retained.
- Python compilation passed for app/scripts/training/migrations/tests. Node syntax checks passed for all four embedded browser scripts. `pip check` reports no broken requirements in the Python 3.12 verification environment. No dependency changes beyond the C3 pins were required.
- The C4 comparison PNG was visually inspected; synthetic-only labeling and scale are visible. Browser button interaction and target-device/frontend integration were not exercised with a visual browser in this delivery; actual routes and end-to-end API calls were exercised over HTTP. Windows/macOS commands are documented, but execution was on Linux/Python 3.12.

No human participant data or real-world intervention effect was evaluated. C4 is deterministic preference/feedback ranking, not a contextual bandit or medical model. Session completion is an unverified user event; neither elapsed time nor a simulated rating establishes adherence or benefit. Real participant sign-in/scoped authorization, TLS/storage protection and approved human validation remain to be provided before an external student study.
