    What this component demonstrates

    A versioned rule policy ranks an original six-activity catalog. A smoothed score uses only this participant’s earlier completed-session ratings. No neural training, paid API, contextual bandit, journal upload or clinical benefit model is involved. The API also accepts owned C1/C2/C3 reference IDs for traceability; these references do not change ranking.
