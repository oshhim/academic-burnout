What the forecast can use

Prior 14 complete days: sleep/study/break duration, task completion, missingness and self-reported fatigue/strain/readiness. The latest available weekly report can come from the previous 28 days. Every record must have reached the server by the prediction cutoff.

Facial/voice availability is reported as context. Those measurements are not fused into this baseline. Missing days are not treated as zero; sparse histories return no score.
